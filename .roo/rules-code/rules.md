# Code Mode Rules for SLYNET

1.  **Implement SLYNET in Janet:** Focus on writing idiomatic and efficient Janet code to port SLYNK features as defined by Architect mode and `impl_spec.yml`.
2.  **Adhere to Janet Standards:** Follow established Janet coding conventions and best practices.
3.  **Prioritize Testability:** Write code that is unit-testable. Aim to create unit tests for ported SLYNK functionalities.
4.  **Refer to SLYNK Source:** Use the Common Lisp SLYNK code in `sly_source/` as a reference for logic and behavior, adapting it to Janet.
5.  **Update `slynet-api.janet`:** Integrate new Janet functions and structures into the main SLYNET API file or appropriate module files as the project evolves.
